Outil **personnel et mono-utilisateur**, entre Manu et Claude. Il maintient Manu
sur **commercial / business development / création** et fait sortir le reste de
ses mains. Ce n'est pas une to-do list.

- **Méthode :** `../../METHODE_DE_CONSTRUCTION.md` (obligatoire avant toute session)
- **Docs projet :** `docs/` — PROJECT_STATE · DECISIONS · ARCHITECTURE · BACKLOG · CHANGELOG
- **Schéma :** `db/001_schema.sql` — schéma `cockpit` sur le projet Supabase « Flex Up APPS »
- **Déployer :** `bash deploy-app-taches.sh`
- **Tests :** `npm test` (tournent aussi automatiquement avant chaque déploiement)

Règle de conception non négociable (D22) : **Claude écrit, Manu corrige.**
Aucun formulaire. Si Manu doit remplir un champ, le design est faux.
